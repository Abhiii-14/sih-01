1. Citizen / Resident Interface

US-01: Report a Civic Issue (Pothole)

Requirement: As a citizen, I want to report a pothole with a photo and location so that the authorities can see exactly where the problem is.













US-02: Track Complaint Status

Requirement: As a citizen, I want to track my complaint status so that I know whether action is being taken.




US-08: Rate the Resolution

Requirement: As a citizen, I want to rate the resolution from 1 to 5 stars so that service quality can be measured. (Note: Only available for 'Resolved' status)














2. Municipal Admin Interface

US-03: Classify Complaints

Requirement: As an admin, I want to classify complaints by category and ward so that they reach the right department.










US-04: Assign Complaint to Field Worker

Requirement: As an admin, I want to assign a complaint to a field worker so that the work is done on time.










3. Field Worker Interface

US-06: Task Overview login confirmation

Requirement: As a field worker, I want to see my assigned tasks so that I can plan my day.




US-07: Resolve Task & Upload Verification

Requirement: As a field worker, I want to mark a task resolved with an "after" photo so that the citizen and admin can see proof of the repair.
