Citizen Complaint Management System

Use the modules below to validate, register, track, and rate a complaint.

Home | Complaint Validation | Complaint Registration | Status Tracking | Feedback and Rating

Start the local server with python complaint_server.py, then open http://127.0.0.1:8000. Complaint IDs are stored in a local database and kept unique.
